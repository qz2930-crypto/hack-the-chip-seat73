# SUBMISSION — seat 73, Hack the Chip (NYU × Annapurna Labs)

Project 2, the kernel agent. A small model (Qwen3-8B on the seat's own Trainium2 chip) writes NKI kernels. A
checker grades each attempt and **translates the verdict into one named change**, and the loop repeats. Every
number is a **rate over n runs**, tagged **[sim]** (nki 0.6 CPU simulator) or **[device]**.

**Headline [sim]:** the final agent (C10) solves **7 of 8 NKI levels in 5/5 runs**, including all three byte-graded
performance levels (L5–L7). Upstream never solved L3 or above. On the Stage-A NumPy ladder it solves **9 of 10**.
Agent-written L3/L4/L5 kernels run correctly on the Trainium2 chip **[device]**. The model never changed; the
checker's messages did.
See `RESULTS.md`.
